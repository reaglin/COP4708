COP4708 — Course Module

Module 2 — Relational Theory and Functional Dependencies

This module establishes the mathematical and theoretical foundations of the relational model, examining sets, domains, tuples, and relations as formal constructs. Learners then explore functional dependencies — their types, inference rules, and role as the primary analytical tool for rigorous database schema design and normalization.

This assignment presents a realistic university course registration dataset and asks students to classify a set of potential functional dependencies as Valid, Invalid, or Partially Valid, providing reasoned justifications for each decision.
