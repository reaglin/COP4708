Lecture 1 - Introduction to Databases

Relational Database: A Definition

A relational database is a type of database that organizes data into tables, where each table represents a specific entity (e.g., customers, products, orders). These tables are related to each other through common fields, allowing for efficient data retrieval and manipulation.

Key Elements of a Relational Database

  1. Tables: The fundamental building blocks of a relational database. Each table has rows (records) and columns (fields).
  2. Rows: Also known as records, these represent individual instances of an entity. For example, a row in a "Customers" table might represent a specific customer with their name, address, and contact information.
  3. Columns: These are the attributes or properties of an entity. In a "Customers" table, columns might include "Customer ID," "Name," "Address," "Email," and "Phone Number."
  4. Primary Key: A unique identifier for each row in a table. It ensures that each row is distinct and can be easily referenced.
  5. Foreign Key: A field in one table that references the primary key in another table. This establishes a relationship between the two tables, allowing for data association.
  6. Relationships: The connections between tables based on common fields. These relationships can be one-to-one, one-to-many, or many-to-many.
  7. Data Integrity: The maintenance of data accuracy and consistency. Relational databases enforce data integrity through constraints like primary keys, foreign keys, and data types.
  8. Structured Query Language (SQL): A standard language used to interact with relational databases. SQL is used to create, modify, and query databases.

In essence, a relational database is a structured way of storing and organizing data, making it easier to manage, retrieve, and analyze information.
