COP4708

Database Security Models, Users, and Application Connections

This module explores the principles and practices that protect database systems from unauthorized access, misuse, and data loss. Learners will study the CIA triad, user roles and privilege management, authentication and authorization mechanisms, SQL injection prevention, and the techniques used to establish secure, efficient application-to-database connections including ORM frameworks and connection pooling.
