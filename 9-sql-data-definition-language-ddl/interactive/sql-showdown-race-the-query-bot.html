SQL Showdown
You vs. the Query Bot

Ten SQL statements. The bot types its answer while you type yours. Submit a working statement before the bot finishes and the point is yours — submit after and the bot takes it. Mistakes cost you nothing but time.

Enter your name first — it has to appear on the sheet you turn in.

How a round works

  1. Read the requirement, then write the statement in your editor. One column per line keeps it readable — and the bot writes it that way too.
  2. Submit any time. If it has errors, you'll get them back line by line. Fix and submit again — there's no penalty for a retry, only for the clock.
  3. The bot's editor is visible. You can read what it's typing. Copying it is legal and slower than knowing the syntax.
  4. Oracle syntax (VARCHAR2, NUMBER, CHAR) is what the bot writes, but ANSI equivalents like VARCHAR and INT are accepted.
  5. Your tables stay live. Everything you create fills in below the editors, so Part 3 and Part 4 run against data you built.
  6. At the end you get a result sheet with your score and every statement you wrote. Print it or screen-capture it for submission.
