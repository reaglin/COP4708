Introduction

Database designs rarely stay the same once an application goes live. Requirements change, new data needs to be captured, and mistakes in the original schema have to be corrected. The ALTER TABLE command is the SQL Data Definition Language tool that lets you change the structure of a table that already exists — adding a column, changing a column's data type or size, removing a column, and adding or dropping constraints such as PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, and CHECK.

What makes ALTER TABLE important in this course is that it changes structure without discarding the rows already stored. That is the key difference between altering a table and dropping and recreating it. It also means you have to think about the existing data: adding a NOT NULL column to a populated table, shrinking a column's size, or adding a foreign key when some rows hold values that do not exist in the parent table can all fail or require extra steps.

As you watch the videos below, pay attention to the exact clause keywords used (ADD, ALTER COLUMN or MODIFY, DROP COLUMN, ADD CONSTRAINT, DROP CONSTRAINT), to how constraints are given names so they can be dropped later, and to any differences in syntax between SQL Server and MySQL. Try reproducing each statement on a small test table of your own so you can see what happens to the rows that were already there.
