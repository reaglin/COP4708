Reference Materials

You will cover many of these in more detail in COP4709. Here are some resources that will get you through the basics.

  1. VIEWS - https://www.w3schools.com/sql/sql_view.asp 
    Views are extremely handy in providing access to a database. You should know what they are and how to use them. They are extremely easy to create and use and in some cases (like Materialized Views) they can provide massive performance improvements in databases. 
  2. Stored Procedures - https://www.w3schools.com/sql/sql_stored_procedures.asp 
    These are heavily used in database development and I personally (on projects I manage) allow access to the database through stored procedures. This allows the database administrator to control access to the database and to specific data. It creates a validation layer at the database level to prevent poor-quality data from being inserted into the database if done correctly.
  3. SELECT INTO - https://www.w3schools.com/sql/sql_select_into.asp 
    This is simply a very handy way to get data into a database. For the project, all the students in the class can create INSERT statements for all of the supplied data or you can divide and conquer. This command can come in very handy in pulling data from one source to  another if the formats are different. 
  4. TRIGGERS - There are no reference materials on triggers in W3 Schools and I highly discourage the use of triggers in database design. If you are in a situation where you will need to use triggers (this happens on legacy projects) I highly recommend you update yourself on the pros and cons of using triggers - https://www.mssqltips.com/sqlservertip/6003/sql-server-triggers-pros-and-cons/
