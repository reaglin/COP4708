Module 14

Cloud and Local Databases

This lesson compares locally hosted database systems with cloud-based database services such as AWS RDS, Azure SQL, and Google Cloud SQL. Students will evaluate the trade-offs in cost, scalability, maintenance, and availability between deployment models.
