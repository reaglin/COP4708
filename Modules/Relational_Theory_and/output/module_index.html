Module 2 — Relational Theory and Functional Dependencies

This module explores the mathematical foundations of the relational model — including sets, domains, tuples, and relations — and introduces functional dependencies as formal design tools. Learners will develop the rigorous conceptual grounding needed for systematic database schema design and normalization.
