Group Project 

This is a group project. 

The course project will be divided into three project assignments. Each assignment will represent a stage/phase of project execution. The project represents a real-life scenario of an organization that will approach you to create an efficient database. Through the questions provided, you will learn how to approach this type of project step by step. The assignment will assist in analyzing complex database problems. It will also help you design, implement, and evaluate the selected solution by identifying database entities, their attributes, and their functional dependencies. The initial build will analyze and capture user forms and requirements. The first project assignment will satisfy SLO1, SLO2, and SLO6.

In the first project assignment, there will be NO CODING, and you will NOT be using MS Access. You may select from either project option in Project Discussion . You will need to familiarize yourself with the data. You will be able to ask questions about the data in the Project Discussion. Your group will have its own Discussion area, but questions about the data (for me) will need to go to the Project Discussion board. 

Project Information

Sandpiper Code Animal Shelter has contracted you to build a database to help manage their records. They have been using paper forms and have had volunteers enter data directly into a Google Docs spreadsheet. The paper forms are available via the link in this assignment. The spreadsheet (in Google Docs) is available in read-only format and is also attached to this assignment. 

For  Project Assignment 1, you will;

  1. Develop a full data dictionary of all data 
  2. Identify the entities and attributes and their functional dependencies,
  3. Develop an Entity Relationship diagram of this data.    

You will have questions. These questions should be posted to the Project Discussion board, and you should review the questions asked by other groups. You should have a single question per post, and the subject should indicate the question; this will make it easier for you to find information that will help you complete the project.  

For this assignment, you will need information to support the design. By reading the requirements in Assignment 4, you will be able to make better design decisions at this stage.

All assignments should be submitted in a formal report format (See Guide to Writing Good Reports ) and in Word or PDF format.
