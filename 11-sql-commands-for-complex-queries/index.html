11 — SQL Commands for Complex Queries

This module takes you beyond basic SELECT statements into the full power of SQL — exploring JOINs, WHERE clause filtering, sorting, aggregation, and subqueries. Work through the artifacts below in order to build a solid foundation in writing sophisticated, real-world database queries.
