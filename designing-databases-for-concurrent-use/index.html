COP4708

Designing Databases for Concurrent Use

This module explores the principles and techniques required to design robust database systems that support multiple simultaneous users. Topics include ACID transaction properties, common concurrency anomalies such as dirty reads and phantom reads, and the locking mechanisms used to ensure data integrity in multi-user environments.
