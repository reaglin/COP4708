COP4708

Designing Databases for Concurrent Use

This module explores the challenges and solutions surrounding multi-user database environments. Topics include ACID transaction properties, common concurrency anomalies such as dirty reads, non-repeatable reads, and phantom reads, as well as locking mechanisms and isolation strategies that ensure data integrity in shared systems.
