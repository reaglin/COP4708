COP4708

Designing Databases for Concurrent Use

Explore the principles and techniques required to build robust database systems that support multiple simultaneous users. This module covers ACID transaction properties, common concurrency problems—including dirty reads and phantom reads—and the locking mechanisms used to maintain data integrity in shared environments.
