Original Assignment (Complete this or Alternate Below)

In this assignment, you need to analyze the given relation (table) and identify every possible functional dependency. This will help you understand determinants and how to use them to determine other fields within a table. In addition, you will learn how to normalize a relation based on Boyce-Codd Normal Form (BCNF).  This assignment will satisfy course outcome 1, which is connected to SLOs 1 and 6

This assignment must be completed and written individually. If you need external resources, some simple Google or AI searching and questions can help.

NOTE: See below for an alternate method to complete this assignment. 

Hint: You should be able to identify at least 3 tables in the final design.
Hint: Candidate keys that are not used as the primary key are still useful in searching records. (For example, we can find your records with your student ID, but we can also find them with your SSN)

Assignment Statement below (also in attached PDF and Doc formats). Note: the submission report format is included below the assignment.  

  1. List the major entities identified in the table.
  2. After carefully examining the table, identify candidate keys. (Hint: Remember from the lecture that a candidate key field has to be unique. For example, the combination of first name and last name is not unique and cannot be used as a candidate key. Identify the candidate keys and use some as primary keys to help normalize the table.
  3. Identify the functional dependencies for each entity. (Hint: the identified candidate keys will be used as determinants of other fields. Review the lecture that addresses functional dependencies.
  4. Normalize the Excel sheet to look like a relational database using Boyce-Codd Normal Form (BCNF)
  5. If you have multiple values for the department phone number (the department has multiple phones), what would be the best solution to add the phone to the relational database? Review the lecture titled normalization before answering this question.
