COP4708 — Applied Database

Outcomes:📋 Course and module learning outcomes

Modules

Open a module to see its topics and everything in it.

  • Module 1

    Introduction to Databases, Types, and Applications

    This lesson introduces the fundamental concepts of databases, exploring different types including relational, NoSQL, and hierarchical databases. Students will examine real-world applications and understand why databases are essential in modern software systems.

    15 items
  • Module 2

    Relational Theory and Functional Dependencies

    This lesson covers the mathematical foundations of relational theory, including relations, tuples, and attributes. Students will learn how functional dependencies define relationships between data attributes and serve as the basis for database design decisions.

    21 items
  • Module 3

    Relational Databases and Normalization Concepts

    This lesson introduces relational databases and the core motivation behind normalization, explaining how data anomalies arise in poorly structured tables. Students will explore insertion, update, and deletion anomalies and how normalization addresses them.

    17 items
  • Module 4

    Normal Forms: 1NF, 2NF, and 3NF

    This lesson walks through the first three normal forms in detail, providing step-by-step examples of transforming unnormalized tables into 1NF, 2NF, and 3NF. Students will practice identifying and eliminating partial and transitive dependencies.

    15 items
  • Module 5

    Advanced Normal Forms: BCNF, 4NF, and 5NF

    This lesson extends normalization to Boyce-Codd Normal Form and beyond, covering multivalued dependencies and join dependencies. Students will analyze edge cases where 3NF is insufficient and apply higher normal forms to complex schemas.

    16 items
  • Module 6

    Data Modeling and Entity-Relationship Modeling

    This lesson introduces data modeling concepts and the Entity-Relationship (ER) model, teaching students how to identify entities, attributes, and relationships in a problem domain. Students will create ER diagrams to visually represent database structure before implementation.

    14 items
  • Module 7

    Designing Relational Databases from ER Diagrams

    This lesson covers the systematic process of converting ER diagrams into relational database schemas, including handling one-to-many, many-to-many, and weak entity relationships. Students will practice mapping ER constructs to tables, primary keys, and foreign keys.

    16 items
  • Module 8

    SQL Data Modeling Language

    This lesson introduces SQL as a data modeling language, focusing on how SQL is used to express and implement logical data models in a relational database system. Students will explore schema creation concepts and understand the role of SQL within the broader database design workflow.

    12 items
  • Module 9

    SQL Data Definition Language (DDL)

    This lesson covers SQL DDL commands including CREATE, ALTER, DROP, and TRUNCATE, teaching students how to define and modify database structures. Students will build and manage tables, constraints, and schemas using hands-on DDL exercises.

    17 items
  • Module 10

    Using Keys and Key Types in SQL

    This lesson provides an in-depth look at primary keys, foreign keys, candidate keys, composite keys, and surrogate keys in SQL databases. Students will learn how to define and enforce key constraints to maintain data integrity and support referential integrity.

    15 items
  • Module 11

    SQL Commands for Complex Queries

    This lesson focuses on advanced SQL querying techniques including JOIN types (INNER, LEFT, RIGHT, FULL), WHERE clauses, ORDER BY, GROUP BY, HAVING, and subqueries. Students will write multi-table queries to extract and analyze data from relational databases.

    14 items
  • Module 12

    Normalization, Denormalization, and Practical Database Design

    This lesson revisits normalization in a practical context and introduces denormalization as a deliberate performance optimization strategy. Students will learn to balance theoretical purity with real-world performance needs when designing production databases.

    14 items
  • Module 13

    Designing Databases for Concurrent Use

    This lesson addresses the challenges of multi-user database environments, covering transactions, ACID properties, locking mechanisms, and isolation levels. Students will explore concurrency control strategies to prevent data conflicts and ensure consistency.

    16 items
  • Module 14

    Cloud and Local Databases

    This lesson compares locally hosted database systems with cloud-based database services such as AWS RDS, Azure SQL, and Google Cloud SQL. Students will evaluate the trade-offs in cost, scalability, maintenance, and availability between deployment models.

    16 items
  • Module 15

    Database Security Models, Users, and Application Connections

    This lesson covers database security including user roles, permissions, authentication, and SQL injection prevention. Students will also learn how applications connect to databases using connection strings, ORM frameworks, and connection pooling best practices.

    16 items
