Major SQL Commands

1. Data Definition Language (DDL)

  • CREATE: Used to create database objects like tables, indexes, views, and stored procedures.
    • CREATE TABLE: Defines the structure of a new table (columns, data types, constraints).
    • CREATE INDEX: Creates an index on a table to speed up data retrieval.
    • CREATE VIEW: Creates a virtual table based on the result-set of an SQL statement.
  • ALTER: Modifies the structure of existing database objects.
    • ALTER TABLE: Add, modify, or delete columns in a table.
    • ALTER INDEX: Modify an existing index.
  • DROP: Deletes database objects.
    • DROP TABLE: Removes an entire table and its data.
    • DROP INDEX: Deletes an index.
    • DROP VIEW: Removes a view.
  • TRUNCATE: Removes all data from a table but keeps the table structure intact.

2. Data Manipulation Language (DML)

  • SELECT: Retrieves data from one or more tables based on specified criteria.
    • WHERE: Filters the results based on conditions.
    • ORDER BY: Sorts the results.
    • GROUP BY: Groups rows with the same values into summary rows.
    • HAVING: Filters groups based on conditions.
    • JOIN: Combines rows from two or more tables.
  • INSERT: Adds new rows into a table.
  • UPDATE: Modifies existing data in a table.
  • DELETE: Removes rows from a table based on specified conditions.

3. Data Control Language (DCL)

  • GRANT: Gives users specific permissions on database objects.
  • REVOKE: Removes previously granted permissions.

4. Transaction Control Language (TCL)

  • COMMIT: Saves all changes made during a transaction.
  • ROLLBACK: Reverts all changes made during a transaction to the last commit point.
  • SAVEPOINT: Sets a point within a transaction to which you can later rollback.

5. Other Important Commands

  • USE: Selects a specific database to work with.
  • SHOW: Displays information about databases, tables, and other objects.
  • EXPLAIN: Shows how the database will execute a query.

Summary

These SQL commands provide the foundation for managing a database, allowing you to define its structure, manipulate the data within it, control access to it, and manage transactions. Each command has a specific purpose and can be combined with other commands to perform complex operations.
