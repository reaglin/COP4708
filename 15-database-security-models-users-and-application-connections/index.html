Database Security Models, Users, and Application Connections

    A reading on SQL injection that explains how concatenating user input into queries lets attackers execute arbitrary SQL, why it ranks in the OWASP Top Ten, and the defenses — parameterized queries, input validation, least privilege — that prevent it.

    A reading introducing Object-Relational Mapping frameworks, explaining how classes mapped to tables replace hand-written SQL, the maintainability benefits of abstraction, and the tradeoffs ORMs introduce.
